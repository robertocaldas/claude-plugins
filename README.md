# claude-plugins

Roberto Caldas's Claude Code plugins, in one marketplace. Each plugin lives in its own repo.

| Plugin | What it does |
|---|---|
| [identicon](https://github.com/robertocaldas/identicon) | A GitHub-style identicon of the current repo in a docked pane |
| [superreview](https://github.com/robertocaldas/superreview) | Interactive change diagrams of code changes as a self-contained HTML page |

## Install

At the prompt of a terminal session:

```
/plugin marketplace add robertocaldas/claude-plugins
/plugin install <plugin>@robertocaldas
```

From a shell:

```
claude plugin install <plugin> --marketplace robertocaldas/claude-plugins
```
